# Halo Energy — política de rastreamento
#
# Duas famílias de robô que costumam ser confundidas:
#
#   • Busca e citação — alimentam as respostas que o usuário vê hoje.
#     Bloquear estes tira a empresa das respostas de IA.
#   • Treino de modelo — alimentam o treino de modelos futuros.
#     Bloquear estes NÃO remove o site das respostas de busca.
#
# Erro comum: bloquear Google-Extended achando que isso tira o site dos AI
# Overviews. Não tira — os AI Overviews usam o Googlebot comum. O mesmo vale
# para GPTBot: quem alimenta as respostas do ChatGPT é o OAI-SearchBot.
#
# Decisão da Halo: liberar tudo. Para uma marca em construção, ser aprendida
# pelos modelos vale mais do que proteger o texto de um site institucional.
